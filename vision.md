What is this application?
 - This web application is my personal OS. It will exist to help structure daily routine tasks and declutter.
Who is it for?
 - This web app is currently being built explicitly for my use as a learner and job searcher in the engineering/management space.
What problems does it solve?
 - Currently, I am working on multiple fronts. I am learning new things to enhance my skillset, applying to jobs, networking etc. This information is spread out over multiple interfaces, such as excel sheets, other apps. All this information needs to be coordinated for me to make more sense out of it.
What should the user be able to accomplish without AI?
 - The user should be able to view the calendar, view important dates, file entries for today's work accomplished, get reminders, see what jobs you've applied to at what date at which company.
What should the AI make dramatically easier?
 - The AI should make the process of keeping track of your work easier. It should act as a decision supporter that can keep context of all my work and information over time and tell me what things need my attention the most currently.
What are the project's learning goals?
 - The projects learning goals are:
     - Learn full stack web development: FastAPI, React, SQL, Databases
     - Learn how modern web/AI applications are architected.
     - Learn API design
     - Learn how AI integrates with this tech stack
What are explicitly out of scope for Version 1?
 - The following things are not part of version 1: 
     - User authentication
     - Multiple users
     - Cloud deployment
     - Mobile application
     - Email integration
     - AI
     - Voice
     - External APIs
     - Browser automation
     - Notifications beyond simple local reminders
What is the success criteria for this verion?
- I should be able to
     - Add tasks.
     - Edit tasks.
     - Delete tasks.
     - Track job applications.
     - Track companies.
     - View a calendar.
     - See reminders.
     - Persist data locally.
